Rail adalah jalur yang semakin relevan bagi kendaraan, kits-down dan bagian-bagian yang menuju Eurasia, dan Cina telah membangun sebuah mode dukungan di sekitar Kereta Api Cina-Eropa Express: kereta api "transit cepat" (铁路快通) pengaturan bea cukai. Modus menyerang botol tertentu - ulang deklarasi transit dan kertas waybills di setiap pelabuhan kereta api domestik - dengan membiarkan elektronik melalui - waybill data drive satu, data - deklarasi yang dikirim. Panduan ini menjelaskan apa mode berubah, dua saluran untuk menggunakannya, yang menyediakan fasilitas, dan titik yang tepat di mana fasilitas Cina-sisi berakhir dan terus rute luar negeri verifikasi harus dimulai. Ini tidak mengutip tingkat barang, jadwal atau angka loading-gauge, yang route-, carrier-dan cargo-spesifik.

## Menghilangkan batas mode

Tanpa transit cepat, konsinyasi kereta api melintasi pelabuhan rel domestik dapat menghadapi penanganan berulang-formalitas dan kertas-berdasarkan pertukaran waybill, menambahkan tinggal waktu di hub kereta api perbatasan. Transmisi cepat mereorganises ini sekitar data: pembawa kereta api domestik mentransmisikan melalui data elektronik, memungkinkan deklarasi transit dibuat pada satu waktu, basis data-didorong. Modus ini secara progresif digulung keluar ke pelabuhan kereta api nasional dari 2021, menggantikan penanganan pilot terpecah-pecah dengan pendekatan standar domestik.

## Dua saluran untuk menjalankan mode

Pembebas atau pemalsu harus memahami bahwa transit cepat dapat dipicu melalui salah satu dari dua saluran:

1. ** Railway- perusahaan "head-to- head" transmisi data. ** Otoritas kereta api / kapal induk mentransmisikan kombinasi - transportasi waybill data elektronik ke bea cukai pada institusi- to otoritas ("总对总"), yang merupakan rute paling otomatis ketika layanan kereta terpilih mendukungnya.
2. ** Deklarasi Enterprise melalui Jendela Tunggal. ** Dimana saluran pertama tidak digunakan, perusahaan dapat mengajukan deklarasi transit itu sendiri melalui Cina International Trade Single Window.

Saluran mana yang berlaku tergantung pada layanan kereta api, keberangkatan rel pelabuhan dan operator operasi; ini adalah item konkret untuk mengkonfirmasi ketika pemesanan daripada mengasumsikan.

## Langkah-langkah Imputasi yang mengikuti

Setelah pengiriman berada di bawah mode cepat transit, termasuk prosedur pemeriksaan prioritas **, * ijin untuk tranship / reload ** (换装) sebagai bagian dari aliran transit, dan ** manifest consolidation ** (舱单归并) sehingga pengelompokan kargo kereta api tidak menghasilkan filings paralel berlebihan. Untuk sebuah shipper memindahkan banyak kontainer bagian atau unit knock-down pada satu kereta api, manifest konsolidasi dan penanganan prioritas adalah di mana waktu praktis tabungan muncul. Ini adalah ukuran-ukuran sugesti, bagaimanapun, bukan pengabaian kepatuhan: barang, lisensi dan persyaratan komoditas yang berlaku untuk ekspor apapun yang masih berlaku.

## Dimana China- sisi Advantasi berakhir

Seorang eksportir disiplin menarik garis yang jelas antara Cina dan luar negeri segmen.

- ** China sisi (tercakup oleh mode ini): ** Transmisi data domestik, satu kali deklarasi transit, inspeksi prioritas, diizinkan pengiriman dan konsolidasi manifes di pelabuhan rel Cina.
- ** Bagian Luar laut (tunggal sumber / route-spesifik): * luas-gauge melawan standard- gauge ** roda atau bogie transfer ** di perbatasan, dan ke 衔接 melalui koridor masing-masing, tergantung pada koridor tertentu, kereta api luar negeri dan setiap negara sendiri cukai pengobatan. Ini harus dikonfirmasi ** rute oleh rute **; mode cepat China transit tidak menentukan mereka.

Secara kritis, panduan ini tetap di sisi Cina: tidak memberikan ijin pada tugas negara, mengimpor pajak atau pembatasan dalam transit atau negara tujuan, dan tidak menyediakan ukuran kendaraan atau memukul nilai kendaraan. Mereka milik route- spesifik carrier dan overseas- otoritas verifikasi. Kendaraan yang cocok dengan mobil datar rel Cina tidak otomatis dibersihkan atau secara dimensi dibersihkan untuk setiap rel kereta api hilir.
