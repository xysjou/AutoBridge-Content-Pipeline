ケニアは、税制当局と標準体との間の車両の輸入を分割し、基準ステップは大幅です**車両が原発国を離れる前に**。 **ケニアの収入局(KRA)**は、税関評価、職務およびクリアランスを処理します。**Kenya Standards(KEBS)**は、規制された輸入がケニア基準を満たしているかどうかを決定するコンフォーマティ(PVoC)プログラムの事前輸出検証を実行します。 これは、ケニア固有のガイドです。 関連する数字とリストは時間感度であり、現在のKRA / KEBSソースから読み込まれる必要があります。

## KEBS PVoC:輸出の前に確認される適合

PVoCは輸出国で適用される適合保証プログラムです:任命された点検会社はプロダクトを確かめます–モーター車、移動式装置および使用された予備品を含んで、KEBS PVoC操作マニュアルの熱心なセクションで覆われる–郵送物の前に適当な標準を満たします。 指定されたPVoCエージェントから適合証明書は、クリアランス文書KRAが規制製品に期待する一部であり、プログラムのルートが適用されると、KEBSガイドラインに従ってインポート標準化マーク(ISM)が発行されます。 現在のPVoCマニュアル(バージョン14)は、国や車両検査の代理店を指すので、輸出業者は、実際の出荷のために中国をカバーするかどうかを確認する必要があります。

- KEBSが検査エージェントが自動車の原産国にどの検査をしているかを確認します。
- 船舶運航前に、CoCを取得するために、事前に輸出検査を手配する。CoCは到着後、安く再建することはできません。
- CoC、請求書、VIN/unitの詳細を一致させます。KRAクリアランスを複雑にしています。
- 該当する場合、KEBS インポート標準化マークガイドラインに記載された ISM ルートに従ってください。

## KRA: 税関手続きと税務スタック

KRAは、モータ車両輸入が単一の輸入義務ではなく、HS分類により異なるスタックに含まれていると述べています。輸入関税プラスの有利、VAT、輸入宣言料、および鉄道開発リービーは、所定の料金で、すべての支払いがリリース前に行われます。 KRAは、取引価格を上回ることができる独自の評価フレームワーク(中古車向け現在の小売販売価格データベース)を使用して、車両を値します。 認可された通関業者は、該当するCoC / ISM、請求書、その他の輸入文書によってサポートされている宣言をファイルします。

## 車両年齢規則が転がり、現在のKRA文を読みます

ケニアは輸入中古車年齢をコントロールし、KRAは転がり製造年を出版する(税関FAQは、現在許可されている製造年を状態に)。 カットオフが時間をかけて前進するので、  an exporter must not hard-code a fixed 'eight-year' or any other number into a sales pitch; 正しい行動は、出荷時の現在のKRAステートメントを確認し、特定のユニットの製造日と比較することです。 右手ドライブと道路安全/排出の期待も適用され、狭い免責のみ。

## 中国・ケニア車両の取扱業務の受注

1. 単位が注文を受け入れる前に**current** KRAの位置に対してケニアのステアリング/年齢の予想を満たしていることを確認します。
2. KEBSが特定した事前輸出入検査を予約し、原産国PVoC CoCを取得。
3. CoCとVINと一貫性のある請求書、梱包/ユニットリスト、B/Lを用意します。
4. ケニアの輸入業者の清算エージェントファイルKRAのエントリーをし、KRA評価の現在のデューティースタックを解決してください。
5. PVoC の経路が要求するISMを得て下さい、そして整理および登録を完了して下さい。

## 中国側輸出業者が取引を失う場所

- 変更以来、固定年齢制限または義務を切断する。 PVoC CoC が存在する前に出荷; 左手ドライブまたはオーバーエイジユニットを提示すると、市場は登録できません。 CoC とインボイスの不一致。 KEBS 任命 PVoC のきれいな中国検査代替品を仮定します。

## よくある質問
**中国やケニアでKEBS検査が行われるの? アパート**

PVoCはKEBS任命された代理店によって輸出国で行われる前輸出プログラムです;CoCはそれからケニアの整理を支えます。

**Is import duty a single percentage?**

いいえ — KRA は、HS、エンジン、年齢によって異なるデューティープラスの有利、VAT、輸入宣言、および鉄道関連を適用します。 現在の KRA 数字を使用します。

**輸入車の最大年齢は? アパート**

定番ではなく、出荷時の許容年数をKRAが発行する転造製造年ルールです。

**ISMとは? アパート**

インポート標準化 該当するPVoCプログラムを経由してルートされたインポートのためのKEBSガイドラインで発行されたマーク。

**輸出業者は車を直接取り除きますか。 ふりがな ふりがな**

ライセンスのケニアの清算代理店は、通常、レコードの輸入業者の通関手続きを手配します。輸出業者は文書とCoCに準拠しています。
