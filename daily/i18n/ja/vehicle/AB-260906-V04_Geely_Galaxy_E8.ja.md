## バッテリー and CLTC レンジ — トリムごとに読み込まれる never as one number
China源は、複数のリチウム電池パック(LFPおよび一線を渡る十分に62 / 67.8 / 76 kWh)とCLTCの範囲を記述し、異なる電池と駆動の組み合わせに取り付けられた575 / 610 / 620 / 700 km。 現在、単一ソースと、実際のSKUのOEM構成シートで、正確なバッテリー間距離を測るマッピングが確認されている必要があります。 このページは間違いなく は固定の 'battery X = range Y' テーブルを印刷しないので、ソースをマッピングしても完全にロックされていないと主張するので、 ' を非公開にします。

## ソフトウェア、OTAおよびコックピット
E8は、大型の統合ディスプレイとGeelyの車載オペレーティングシステムを中心に構築されており、さらには、過剰な更新が行われます。 輸出バイヤーのために、これは、任意のChina市場EVと同じ勤勉さを上げます:言語の可用性、アプリストア地域、マップデータ、SIM /接続バンド、およびOTAがChina外で機能するかどうか。 これらは、想定されるものではありません。-VIN受諾チェックに含めます。
## EV固有の輸出検証
1. 正確なSKUを締め、電池化学/キャパシティ、モーター レイアウトおよびLCCのレコードからCLTCの範囲を得て下さい。
2. 確認 400V 対 800V プラットフォームのSKU と正式充電曲線/ピークの充電時間の前に.
3. コネクター/標準(GB/T 対の宛先)およびアダプターか輸出造る条件を解決して下さい。
4. 海脚のバッテリー輸送分類とキャリアルールを確認します(IMDG/UN分類ガイドを参照してください)。
5. 受入前に目的地のコックピット言語、接続バンド、OTAの動作をテストします。
6. Chinaの市場はLHDです; 任意の輸出ビルドのためのステアリングは、別のOEMの証拠を必要とします。
