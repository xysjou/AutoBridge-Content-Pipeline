## Buyer Context: a Coach Is Sold by Layout and Announcement Code
A 12-metre coach is not a fixed-spec passenger car. The ZK6122 is a highway/tourism coach platform (HQ/H9 sub-lines) whose seating, engine and emission level are set by the specific homologated model code and interior layout. This page is a Chinese-market reference (Chinese-market reference); export builds are configured to order and differ from the domestic unit. Treat platform-level figures as indicative and bind every order to its model code.
## Platform and Seating
- Length class: 12-metre highway/tourism coach platform.
- Seating: approximately 24–55 seats depending on layout (one independent source; the closely related ZK6129 platform is documented at 24–50). Seat count is a layout/approval outcome, not a fixed number — request the seat-plan and model code.
- Sub-lines referenced in Chinese records include ZK6122HQ and ZK6122H9.
## Powertrain (platform-level reference only)
Coach powertrains are selected at order time from Yuchai / Weichai diesels. The figures below come from same-platform references, not a ZK6122-specific OEM sheet, and must be reconfirmed against the chosen model code:
- Reference Yuchai 8.87 L ≈ 360 PS, or Weichai 9.5 L ≈ 375 PS (one independent source, platform reference).
- Confirm engine model, displacement, power, emission stage (China-V/VI), gearbox, rear axle and GVW on the exact announcement code — do not present these reference engines as the fixed ZK6122 specification.
## What the Official Record Confirms (confirmed by primary sources)
The Chinese Ministry of Ecology and Environment (MEE) vehicle emission type-approval list (batch 16) includes the ZK6122 across multiple China-V model entries — an official primary record establishing the model's domestic emission-approval lineage (see source PDF). Scope note: this confirms China emission approval for listed configurations; it is not, by itself, destination-market type approval.
## Documented Export Deliveries (records, not specs)
- 45 ZK6122H9 units delivered to Angola and 168 units to Uzbekistan are recorded by Chinese party media.
- ZK6122HQBA units served the FIFA World Cup in Russia (Chinese media report).
These are delivery/usage records showing the platform has been exported; they do not establish a uniform export specification. Build and emission content for those deliveries was order-specific.
## Build and Durability Notes
Yutong's Y.E.S cathodic electro-coating body treatment and thermal-management measures are cited in Chinese coverage (one independent source) as corrosion/heat measures — relevant to hot/humid or salt-adjacent routes, but verify the exact treatment and warranty for the export build.
## What Importers Should Verify Before Payment
- For a coach the driven/rear-axle arrangement and final-drive ratio are order-critical: pull them from the homologated chassis code, since the reference pack fixes platform and seating but not the drive-axle layout.
1. Exact model code + seat plan (24–55 range is layout-dependent).
2. Engine/gearbox/axle/GVW and emission stage for that code; destination emission/type-approval route.
3. LHD/RHD, door layout, luggage-bay volume, climate (AC) spec for the operating climate.
4. PSI before shipment — VIN/model-code consistency, mileage, body and seat count (see PSI guide).
5. Parts, service and warranty for the chosen Yuchai/Weichai engine in-market.

## Frequently Asked Questions
How many seats does a ZK6122 have? Roughly 24–55 depending on layout and homologated model code; the seat plan must be specified per order.
Which engine is fitted? It is selected from diesel options (platform references include Yuchai ~360 PS and Weichai ~375 PS); confirm the exact engine on the model code rather than assuming one.
Is the ZK6122 officially certified in China? Yes — MEE emission type-approval lists include ZK6122 China-V entries; destination approval is a separate process.
Has it been exported before? Chinese media record ZK6122H9 deliveries to Angola and Uzbekistan and HQBA service in Russia; these are delivery records, not a uniform export spec.
Why can't you quote one fixed specification? A coach platform is configured by layout and model code; only that code fixes engine, seats, GVW and emission level.
