# 多语言SEO交接：内容已备齐，收录不能保证

本交付是GitHub内的待终审稿件，不是线上页面部署或收录证明。所有24份正文与同名元数据应一起使用，不得只翻译标题或导航。适用范围以每篇正文为准，不应为关键词扩展加入未证实的价格、库存、出口或性能承诺。

## 已准备

- 12种语言：en、fr、de、es、pt、ja、ko、vi、th、id、ar、zh，每题各12份全文。
- 各语独立Title、Meta description、H1、摘要、FAQ、来源、ALT、图注、内链锚文本和原创示意图。
- 英文slug保留不翻译；`suggested_path`只是建议路径，不是已部署或已排除冲突的URL。
- 内链只指向已实际打开的英文vehicles/guides目录，未虚构语言版本路由。

## 获准发布后的部署核验清单（本轮未执行）

1. 先人工终审、核对本站全量历史与实际路由冲突，确定每种语言的最终独立URL。核实车辆与商业承诺，不把本稿当报关或交易依据。
2. 每页输出本语言完整可读取正文、唯一H1和对应title/description；阿拉伯语页面使用RTL布局。图片ALT和可见图注使用同语元数据。不要把内部审核记录作为面向买家的卖点。
3. canonical应匹配最终页面URL，不要将全部翻译页统一canonical到英文页。语言替代链接采用完全限定URL，并在每个版本列出自身与所有真实替代版本，双向对应；仅在落地页真实存在后设置x-default。
4. 验证页面HTTP状态、robots、noindex、canonical、导航与渲染可见性，再生成与真实URL一致的站点地图。草稿未获准发布前不要为追求收录擅自移除保护。
5. 上线后使用有权限的Search Console检查实际URL；只有取得对应证据才能称已被发现、已抓取或已收录。它们是不同状态。提交站点地图或请求抓取均不保证收录。
6. 不虚构作者资历、测试结果、评论/星级、售价、库存或结构化数据。FAQ存在不等于保证获得富媒体结果。
