# 中古車購入で確認するブレーキと駐車ブレーキの記録

「ブレーキ整備済み」は確認の出発点ですが、現在の状態を十分に説明する言葉ではありません。請求書に修理が記載されていても、点検した車軸、測定部品、適用限度、駐車ブレーキ不具合の解消状況が分からないことがあります。海外の購入者や車両管理担当者には、引き渡しを受け入れる前に、車両と点検結果、完了した作業を結び付けることが重要です。

本稿は資料の集め方を提案するもので、自分で点検や修理を行う手順ではありません。共通のパッド厚、ディスク限度、液交換間隔、法的合格基準も設定しません。資料は専門家の理解を助けますが、実車点検に代わらず、遠隔で走行適性を認定するものでもありません。警告、漏れ、制動不良が未解決なら、受け入れを保留して有資格者の評価を求め、独自の走行試験や坂道試験は避けてください。

## 発見事項、修理、修理後確認を分ける

発見事項は何が観察されたかを示します。請求書は請求または実施された作業を示し、修理後記録は整備工場が結果をどう確認したかを説明します。一つの文書が全部を含む場合もありますが、「後輪ブレーキ作業済み」だけで三つが完了したとは判断できません。

各書類を VIN などの信頼できる識別情報に結び付け、点検日と記録された走行距離、整備工場の名称、作業範囲を求めることを勧めます。これは編集上の購入提案であり、世界共通の法定記載事項ではありません。不足情報は問い合わせ、曖昧な請求書を広い保証に読み替えないでください。

新しい請求書でも、有用性は作業範囲とその後の履歴によります。後から生じた苦情、警告、未完了のブレーキ作業がないか確認しましょう。古い書類が必ず無意味なわけではなく、新しい日付も現在の良好な状態を保証しません。どの購入上の疑問に答える資料なのかが重要です。

## 「良好」ではなく部位別の結果を求める

米国向け 2024 Toyota 86 の整備資料は、資格を持つ技術者に、ライニングやドラムの損傷・漏れ・摩耗、パッド／ディスクの摩耗・振れ・漏れを点検するよう指示しています。これは点検の詳しさを示す特定資料の例であり、すべての車が同じ部品や手順を持つという意味ではありません。Brembo も最小厚、溝、亀裂、表面変色、変形を点検上の懸念として挙げています。

販売車両については、装着部品、位置、関連する測定を明示した専門家の報告を求めましょう。測定値と併せて、適用メーカー限度と参照元を整備工場に記載してもらいます。部品の特定や比較基準のない数値は判断しにくく、別車種から転記した一般値では代用できません。

| 求める記録 | 購入時に分かること |
|---|---|
| 車軸と部品の識別 | どのブレーキを点検・交換したか |
| 単位付き測定とメーカー参照 | 何を根拠に状態を判断したか |
| 漏れ、損傷、腐食の所見 | 厚さ以外に何が残っているか |
| 部品と作業を記した請求書 | 所見に対して何を変更したか |
| 修理後確認と未解決事項 | 何が解決し、何が残るか |

この表は機械点検の順序ではありません。方法と限度は対象車両と適切な整備工場に委ねるものです。写真があれば車両と部品位置を対応させてもらいましょう。写真は補足資料にはなりますが、すべての測定や見えない状態を単独で証明しません。

## ブレーキ液と電気自動車の腐食は別に確認

パッド交換の記録だけでは、ブレーキ液に何を実施したか分かりません。液に関する整備記録と、現行メーカー指示を当該車両にどう適用したかの説明を求めてください。本稿は共通交換間隔を示さず、購入者に系統を開けることも勧めません。

ベルギー向け英語版 Model 3 マニュアルでは、独立工場や自分で行った作業も含めて整備概要の正確性は所有者の責任とされています。また、ブレーキ液量の点検を Tesla または専門整備工場に限定しています。この例では整備概要と裏付け記録を併読し、指定点検は専門家に任せるべきです。一市場のマニュアルをすべての車両向け手順に広げないでください。

アイルランド向け英語版 Model 3 マニュアルは、回生制動で摩擦パッドの使用が減っても、さびや腐食は蓄積し得ると説明し、車輪を外して定期的に目視点検するよう示しています。引用の目的は適切な専門点検の記録を求めることで、購入者の車輪脱着を指示することではありません。パッドの使用が少なく見えることや電動車であることは、ブレーキ状態の確認を省く理由になりません。この資料も全 EV 共通の点検間隔を定めていません。

## 駐車ブレーキは装着システムを先に特定

「電動駐車ブレーキ」は単一の機構名ではありません。HELLA は Audi A8 と BMW 7 Series の例で異なる構造を説明しています。購入者は修理内容を解釈する前に、実際に何が装着されているか確認するとよいでしょう。

TRW の EPB ガイドは、訓練された専門家が OEM 仕様に従って作業することを求め、対象システムの診断整備モードと修理後校正を説明しています。すべての電動駐車ブレーキが同じ外部診断機や作業順序を要するとの根拠にはなりません。

修理済みとされる場合は、システム、当初の症状、適用手順、完了作業を整備工場に示してもらいます。適用手順に診断モードや校正が含まれるなら、その完了記録を求め、残る警告や再発も確認します。これは専門記録の依頼であり、自分で操作、整備モードへの移行、保持力試験を行う指示ではありません。

## 説明を求める場合と受け入れを待つ場合

一貫した資料は、販売車両と所見、作業、修理後確認を対応させます。商談には役立ちますが、遠隔の安全証明書ではありません。商業上の受け入れと安全使用に関する専門判断は分けて扱ってください。

測定の参照や部品位置が欠ける場合は、販売者を通じて発行元工場に説明を求めましょう。資料が矛盾する場合も、安心できる方を選ぶのではなく個体に即した説明を求めます。警告、漏れ、制動不良、駐車ブレーキ懸念が残るなら、受け入れを延期し、専門評価と必要な是正を手配することを勧めます。

複数台購入では車両ごとに資料を保管してください。サンプル報告や車隊全体への声明は各個体の状態を証明しません。輸入購入を約束する前には、適切な地元業者が装着システムを整備し、対応資料を入手できるかも確認しましょう。購入時に車両への適用、文書改訂、現在のサービス提供状況を再確認します。

## よくある質問

### 請求書だけで引き渡しを承認できますか？
作業の記録にはなりますが、現在の状態報告とは限りません。所見と適切な修理後確認、必要に応じて専門家の実車点検を求めてください。

### パッドやディスクの最低厚さはいくつですか？
本稿に共通値はありません。専門工場が部品とメーカー限度を特定し、その参照と共に測定値と単位を記録することを勧めます。

### 回生制動なら整備は不要ですか？
いいえ。引用した Model 3 資料は、パッド使用が少なくても腐食があり得るとしています。EV 全般を例外にせず、実車に合う指示を適用してください。

### すべての電動駐車ブレーキに診断モードが必要ですか？
そう仮定しないでください。システムと手順は異なります。TRW は対象システムを説明しており、専門工場に車両固有の手順と完了記録を求めます。
