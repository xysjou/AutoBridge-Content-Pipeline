# 豪州向けDeepal E07 MY25：荷物と経路からRWDかAWD Performanceを選ぶ

Deepal E07で考えたいのは、電動SUVがピックアップのように見えるかではなく、形を変えられる後部空間が実際の運搬に役立つかです。ここで扱う豪州仕様では、RWDの方がWLTP複合推定航続距離は長く、AWD Performanceの方が出力とトルクは大きくなります。どちらも荷物の寸法、充電環境、個別車両の書類確認は欠かせません。

基準はDEEPAL AustraliaのMY25仕様表、v1:2版、2026年9月時点の情報で、文書コードはDPL7855/MY25/09.26です。発行年がMY25をMY26に変えるわけではありません。試乗記事の見出しに別の年があっても、この識別情報の代わりにはなりません。対象は豪州導入初期の5人乗りバッテリー電気式E07で、他市場との同一性は示していません。

## 運ぶ物から考える

後部ガラスとテールゲートの構造により荷室へのアクセスが変わります。目を引く写真より、運ぶ機材の形が重要です。物の寸法を測り、後席を使用する頻度を考え、公式説明に沿った実演を販売者に依頼しましょう。写真に写る開放状態が、そのまま走行可能な状態とは限りません。

仕様表には前部131リットル、閉じた後部524リットル、後席を畳んだ状態1654リットルとあります。これは空間の容積であり、公道上の積載重量や特定の箱の収納個数ではありません。開口部と床面の寸法を求め、重量制限は別に確認してください。「Multitruck」という名称だけで、あらゆる業務用ピックアップの代わりになるとはいえません。

## 駆動方式別の比較

出典：[DEEPAL Australia E07仕様表](https://www.deepal.com.au/media/gzupdrje/deepal_e07_spec_sheet_web.pdf)、MY25、2026年9月v1:2版。両列とも豪州導入初期のバッテリー電気式E07です。WLTPは実験室での複合推定航続距離にのみ適用され、その他は技術仕様です。

| 項目 | E07 RWD | E07 AWD Performance |
|---|---|---|
| 駆動 | 後輪駆動 | 全輪駆動 |
| バッテリー容量 | 89.98 kWh | 89.98 kWh |
| 電池の化学系 | 三元系リチウム | 三元系リチウム |
| 出力 | 252 kW | 440 kW |
| トルク | 365 Nm | 645 Nm |
| WLTP複合推定航続距離 | 550 km | 510 km |
| AC充電最大出力 | 7 kW | 7 kW |
| DC充電最大出力 | 240 kW | 240 kW |
| 接続 | Type 2 AC・CCS2 DC | Type 2 AC・CCS2 DC |

公表航続距離を優先するならRWDから比較するのが自然です。AWD Performanceは、より高い出力とトルク、全輪駆動を求める選択肢です。同じ容量でも航続距離は置き換えられず、AWDの表示だけで特定の悪路への適性も証明できません。高出力版が所有体験のすべてを改善するとは限らないため、用途に沿って選びましょう。

WLTP値は実験室の推定値です。牽引時、満載時、特定の天候で同じ距離を保証しません。ここでは架空の実走行値を補いません。経路計画では、対象車が充電できる場所と、予定の充電地点が使えない場合の代替案が重要です。

## 最大出力と充電計画を分ける

仕様表はDC最大240 kW、30–80%を15分としています。これはメーカーが示す特定区間の値であり、満充電時間、全セッションで維持される出力、すべての充電器での保証ではありません。販売者の説明の条件と、予定設備が対象車に適しているか確認してください。

AC最大出力は7 kWで、ACはType 2、DCはCCS2です。ただし公式資料間でAC充電時間の説明が異なるため、ここでは確定した満充電時間を示しません。DEEPALまたは責任を持つ供給者に、車両と設備を特定して説明を求めましょう。都合のよい公開時間だけを選んで夜間充電を計画しないことが大切です。

## 寸法と牽引は別の確認項目

豪州仕様表の寸法は全長5045 mm、全幅1996 mm、全高1680 mm、ホイールベース3120 mmです。駐車、進入路、積み下ろし場所を確認してください。SUVという分類だけでは収まりのよさを保証できません。実演は自身で評価する機会であり、AutoBridgeの走行試験ではありません。

両仕様とも最大牽引重量は制動装置付き1500 kg、制動装置なし750 kgです。豪州の仕様値であり、仕向地の許可や特定の積載状態の組み合わせを計算した値ではありません。牽引・重量関係の書類、適合装備、使用地の規則を確認しましょう。別々の資料の質量を差し引いて積載量を推定したり、静止時の平台耐荷重を公道での積載上限と扱ったりしないでください。

## 操作と維持管理も実演で確認

前ダブルウィッシュボーン、後マルチリンク、エアサスペンション、15.4インチタッチスクリーン、ヘッドアップディスプレイが記載されています。操作や整備支援について質問する材料にはなりますが、特定の乗り心地を証明するものではありません。よく使う機能を試し、仕向地で誰が対象車を支援できるか尋ねましょう。

スペアタイヤではなくパンク修理キットが記載されています。救援が容易でない地域へ行くなら、実際の付属品と支援体制を確認したい点です。装備表は路上修理手順ではなく、あらゆるタイヤの問題をキットで解決できる保証でもありません。

## 購入前の質問

### 2026年9月版なら2026年モデルですか？

いいえ。文書コードはMY25です。発行年で置き換えず、個別車両の識別情報と製造情報を確認してください。

### AWD Performanceの方が公表航続距離は長いですか？

いいえ。WLTP複合推定値は510 km、RWDは550 kmです。AWD Performanceは出力とトルクが上回ります。

### 荷室容積から積載重量がわかりますか？

わかりません。リットルは空間です。対象車の重量上限と積載書類を求めてください。

### 豪州仕様があれば海外注文できますか？

それだけでは不十分です。在庫、価格、輸出資格、登録、保証、現地支援は別途確認が必要です。中国市場との同一性や別の動力方式も示していません。駆動仕様、充電情報、積載書類が見積対象車に結び付かない場合は、手付金を保留しましょう。

問い合わせには駆動方式、MY25参照版、荷物、充電計画を記し、VIN対応の資料を求めます。[車種一覧](https://www.autobridgeexport.com/vehicles/)や[購入ガイド](https://www.autobridgeexport.com/guides/)も参照できます。
